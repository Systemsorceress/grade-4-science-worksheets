🗝️ NEW TOOL

What Is a Classification Key?

🗝️ A classification key helps us identify and classify living things.

It uses a series of questions. The questions usually have two possible answers.

Does it have flowers?
YES
🌸 Flowering plant
NO
🌿 Non-flowering plant
❓ ASK GOOD QUESTIONS

Good Classification Questions

❌ Not useful

"Is it a nice plant?"


"Is it interesting?"


These are based on opinions.

✅ Useful

"Does it have flowers?"


"Does it have feather-like leaves?"


These are observable features.

✔ A good classification question is clear, observable and can usually be answered Yes or No.
🔀 OPEN OR CLOSED?

Classification Keys Use Closed Questions

❓

Open question

What does the leaf look like?


There could be many answers.

✅❌

Closed question

Does the leaf have a jagged edge?


YES or NO

🗝️ Classification keys mainly use CLOSED QUESTIONS.

🚫 COMMON MISTAKES

Watch Out!

❌ Avoid

  • Is it pretty?
  • Is it interesting?
  • Tell me everything about it.

✅ Better

  • Does it have flowers?
  • Does it have large leaves?
  • Does it have feather-like leaves?
🔬 Ask questions about features that we can actually observe.
